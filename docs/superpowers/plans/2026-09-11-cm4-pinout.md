# Интерактивный pinout CM4 2×100 для baseboard — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Один самодостаточный файл `cm4_pinout.html` — кликабельная схема обоих 100-пиновых разъёмов CM4 с полной справкой по каждому пину (даташит) и слоем «Проект» с утверждённой раскладкой под baseboard антенного трекера.

**Architecture:** Данные слоя «Даташит» генерируются скриптом из PDF (`tools/extract_datasheet.py` → `data/cm4_datasheet.json`), слой «Проект» пишется руками (`data/project.json`), `tools/build.py` вшивает оба JSON в HTML между маркерами. Страница — vanilla JS без сборки и внешних зависимостей: SVG-схема «CM4 вид сверху», панель пина, фильтры, поиск, таблица 200 строк с копированием CSV, блок фактов для трассировки. Чистые функции страницы вынесены в блок `LIB` и тестируются в node.

**Tech Stack:** HTML/CSS/vanilla JS (один файл), Python 3.13 (stdlib + `pdftotext` из poppler-utils) для извлечения данных и сборки, `python3 -m unittest` для тестов данных, `node --test` (node 24) для тестов LIB, Playwright (python, уже установлен с Chromium) для браузерных тестов.

**Spec:** раздел «Спецификация» ниже в этом же файле. Задача 1 копирует его в `docs/superpowers/specs/2026-09-11-cm4-pinout-design.md`, а этот план — в `docs/superpowers/plans/2026-09-11-cm4-pinout.md`.

## Context

Проект «Антенна мечты» переезжает с Raspberry Pi 4 + HAT (страница `rpi4_hat_pinout_v4.html`, 40 пинов) на CM4 на собственной baseboard. ТЗ на плату — `Антенна мечты_baseboard (2).md`, блок-схема — `scheme_future_ant.pdf`. Трассировщику нужен один документ, где по клику на любой из 200 пинов CM4 видно: что это по даташиту (сигнал, направление, подтяжки, дифф-пара и её импеданс, ALT-функции GPIO) и что с ним делает наш проект (имя цепи, устройство, режим, примечания). Старая раскладка v4 не подходит: нужны два CRSF-канала, четыре UART, SPI на сменный видеомодуль, ключи питания TX, NVMe, две CSI.

Решения, принятые с пользователем: оба разъёма (200 пинов); по умолчанию слой «Даташит», кнопка включает слой «Проект» поверх; раскладка GPIO — утверждённая таблица ниже; таблица 200 строк + копия CSV; блок фактов для трассировки. Не делаем: deep-link на пин, ссылки в PDF.

## Спецификация

### 1. Объём
- Все 200 пинов: J1 (1–100) и J2 (101–200), разъёмы DF40 на CM4.
- Два слоя: **Даташит** (по умолчанию) и **Проект** (кнопка-переключатель). Слой «Проект» добавляет к каждому пину цепь/устройство/режим/статус/примечание, не скрывая данные даташита.

### 2. Данные
`data/cm4_datasheet.json` (генерируется):
```json
{"source": {"cm4": "RP-008168-DS-4-cm4-datasheet.pdf", "bcm2711": "RP-008248-DS-1-bcm2711-peripherals.pdf"},
 "pins": [{"n": 55, "conn": "J1", "row": "odd", "sig": "GPIO14", "grp": "GPIO", "dir": "bidir", "gpio": 14,
           "ds": "GPIO: typically a 3.3V signal, but can be a 1.8V signal by connecting GPIO_VREF to CM4_1.8V"},
          {"n": 116, "conn": "J2", "row": "even", "sig": "PCIe_RX_P", "grp": "PCIE", "dir": "in",
           "ds": "Input PCIe GEN 2 RX positive NB external AC coupling capacitor required",
           "pair": {"partner": 118, "z": 90, "skew": 0.23}}],
 "alt": {"7": {"pull": "High", "alt": ["SPI0_CE1_N", "SWE_N / SRW_N", "DPI_D3", "SPI4_SCLK", "RTS3", "SCL4"]}}}
```
- `grp` ∈ GND, PWR5, PWR33 (включая GPIO_VREF), PWR18, GPIO, ETH, SD, USB, PCIE, CSI0, CSI1, HDMI0, HDMI1, DSI0, DSI1, I2C0, CTRL, RSV, VDAC, ANALOG.
- `dir` ∈ gnd, power_in, power_out, in, out, bidir, nc.
- `gpio` — номер BCM2711 GPIO (GPIO0–27 для GPIO/ID_SD/ID_SC, 44/45 для SDA0/SCL0), иначе отсутствует.
- `pair` — партнёр по дифф-паре, импеданс (табл. 7 — 100 Ω, табл. 8 — 90 Ω) и разбег длины дорожки на самом CM4, мм.
- `alt` — табл. 94 BCM2711 для GPIO0–27: подтяжка при загрузке и ALT0–ALT5.

`data/project.json` (руками):
```json
{"meta": {"title": "Baseboard CM4 — pinout 2×100", "rev": "1", "date": "2026-09-11"},
 "devices": {"CRSF1": {"name": "CRSF TX1 (TBS) · UART3", "c": "#D4537E"}},
 "defaults": {"GND": {"net": "GND", "dev": "GND", "status": "used", "note": "Все GND подключить."}},
 "pins": {"54": {"net": "UART3_TXD", "dev": "CRSF1", "mode": "ALT4 TXD3", "note": "→ CRSF TX1 …"}},
 "ds_notes": {"GPIO": "3.3 В при GPIO_VREF=CM4_3.3V; суммарно ≤50 мА на все 28 GPIO."},
 "facts": ["…"]}
```
- `pins[n]` — явная запись; иначе `defaults[grp]`; иначе пин свободен (`status: free`). У явной записи без `status` статус `used`.
- `status` ∈ used, opt (опционально/резерв), free, nc (не используется), dnc (не подключать — Reserved).
- `mode` — `"ALT<k> <имя>"` (должно совпадать с `alt[gpio].alt[k]`) или `"GPIO"`.
- `ds_notes[grp]` — правило из даташита по группе, показывается в обоих слоях как «Правило».

### 3. Страница `cm4_pinout.html`
- Шапка: заголовок, сегмент-переключатель «Даташит | Проект», поле поиска (номер пина, номер GPIO, сигнал, цепь, устройство, режим, шина `uart3`/`i2c1`/`spi6`/`pwm0`, ALT-имена).
- Легенда-фильтр (чипы): в слое «Даташит» — группы, в слое «Проект» — устройства (+ «Не используется»). Активный чип подсвечивает свои пины и затемняет остальные (opacity .15), таблица фильтруется, панель показывает сводку: имя, число пинов, список «пин — сигнал — цепь» с кнопками перехода.
- Схема (SVG, viewBox 1000×440, контейнер со скроллом по X, `min-width: 900px`): контур CM4 «вид сверху» (Figure 4 даташита: разъёмы на нижней стороне, поэтому вид сверху совпадает с видом сверху baseboard), 4 отверстия, прямоугольник BCM2711, пунктир «Wi-Fi антенна — вырез в земле» у левого края. J1 — верхний разъём, J2 — нижний. В каждом 2 ряда × 50 падов 16×16 px, шаг 18 px. **Пины 1/2 (101/102) — справа, 99/100 (199/200) — слева; нечётный ряд — верхний** для обоих разъёмов. Пад: цвет группы (даташит) или устройства (проект), номер внутри, `<title>` для hover, `tabindex=0`, Enter/Space = клик. Выбранный — сплошная обводка; партнёр по паре — пунктирная; статус `dnc` — красная обводка; `opt` — точечная.
- Панель пина (справа на ≥1000 px, sticky; на узких экранах — фиксированная снизу, до 45 vh, с кнопкой ✕): номер в кружке цвета пина, сигнал, разъём и ряд; в слое «Проект» сверху блок Цепь / Устройство / Режим / Статус / Примечание; затем Группа, Направление, BCM GPIO и подтяжка при загрузке, Дифф-пара (кнопка-переход к партнёру, Ω, разбег обоих), Правило (`ds_notes`), дословная цитата даташита, для GPIO — таблица ALT0–ALT5 с подсветкой используемого режима.
- Клавиатура при выбранном пине: ← = пин n+2, → = n−2 (в пределах разъёма), ↓ из нечётного = n+1, ↑ из чётного = n−1, Esc — снять выбор, фильтр и поиск.
- Таблица 200 строк под схемой: №, Разъём, Сигнал, Группа, Напр., [Цепь, Устройство, Режим, Статус, Примечание — только в слое «Проект»], Пара, Даташит. Строка кликабельна (= выбор пина), скрывается при фильтре/поиске; счётчик «Показано N из 200». Кнопка «Скопировать CSV» — все колонки, разделитель `;`, через `navigator.clipboard`; при отказе — `<dialog>` с textarea.
- Блок `<details>` «Факты для трассировки (даташит CM4)» — список из `project.facts`.

### 4. Слой «Проект»: GPIO (утверждено)
Принципы: UART0 — сервисная консоль (единственный UART bootloader'а); CRSF на UART3/UART4 — только у них RTS не конфликтует с I2C1 (RTS2=GPIO3) и консолью (RTS5=GPIO15), направление half-duplex — аппаратный RTS (PL011 RS485-режим, ядро ≥5.13) либо тот же пин как GPIO; приёмники на SPI6 (GPIO11 занят RTS4); серво на UART5 с авто-направлением на плате; GPS на UART2 (импульсы I2C0-пробы EEPROM при загрузке безвредны); ключи питания на GPIO с pull-down при загрузке. ### 5. Слой «Проект»: остальные пины
- PCIe 102/109/110/112/116/118/122/124 → M.2 M-key NVMe 2280 (CLKREQ#, PERST#, REFCLK, CM4 RX ← PETp0/n0, CM4 TX → PERp0/n0).
- CSI0 (128/130, 134/136, 140/142) + I2C0 SDA0/SCL0 (82/80) + Camera_GPIO (97) → FFC камеры. CSI1 (115/117, 121/123, 133/135, 139/141, 127/129) — резерв (`opt`) под analog→MIPI, тот же I2C0.
- USB 101/103/105 → хаб USB 2.0 (2 внешних порта, LTE-модем, резерв) + прямой путь к ПК для rpiboot.
- Ethernet пары 3–12 → свитч; LED 15/17/19 — `opt`; SYNC 16/18 — `nc`.
- CTRL: GLOBAL_EN 99 ← Ethernet-reboot; RUN_PG 92 ← кнопка reset через 220 Ω; nRPIBOOT 93 ← джампер/кнопка; nEXTRST 100 — `opt`; EEPROM_nWP 20, WL/BT_nDisable 89/91 — `opt` (джамперы); LED 21 (`used`), 95 (`opt`).
- POWER: +5V ×6 `used`; CM4_3.3V 84/86 и GPIO_VREF 78 → цепь CM4_3V3; 1.8V 88/90 `nc`; все GND `used`.
- `nc`: SD_* (eMMC-вариант), HDMI0/1, DSI0/1, AnalogIP0/1, VDAC_COMP. `dnc`: 76, 104, 106.

- [ ] **Step 1: Написать падающий тест**

`tests/test_datasheet.py`:
```python
import json, unittest
from pathlib import Path

ROOT = Path(__file__).resolve().parent.parent
PATH = ROOT / "data" / "cm4_datasheet.json"
GROUPS = {"GND", "PWR5", "PWR33", "PWR18", "GPIO", "ETH", "SD", "USB", "PCIE", "CSI0", "CSI1",
          "HDMI0", "HDMI1", "DSI0", "DSI1", "I2C0", "CTRL", "RSV", "VDAC", "ANALOG"}
DIRS = {"gnd", "power_in", "power_out", "in", "out", "bidir", "nc"}


class TestDatasheet(unittest.TestCase):
    @classmethod
    def setUpClass(cls):
        cls.data = json.loads(PATH.read_text(encoding="utf-8"))
        cls.pins = {p["n"]: p for p in cls.data["pins"]}

    def test_200_pins_sequential(self):
        self.assertEqual([p["n"] for p in self.data["pins"]], list(range(1, 201)))

    def test_spot_checks(self):
        p = self.pins
        self.assertEqual(p[1]["sig"], "GND")
        self.assertEqual(p[55]["sig"], "GPIO14")
        self.assertEqual(p[99]["sig"], "GLOBAL_EN")
        self.assertEqual(p[200]["sig"], "HDMI0_SCL")
        self.assertEqual(p[36]["gpio"], 0)
        self.assertEqual(p[35]["gpio"], 1)
        self.assertEqual(p[80]["gpio"], 45)
        self.assertEqual(p[82]["gpio"], 44)
        self.assertNotIn("gpio", p[97])
        self.assertEqual(p[92]["ds"], "Bidirectional pin. Can be driven low (via a 220Ω resistor) to reset the CM4 CPU. "
                         "As an output, a high signals that power is good and CPU is running. Internally pulled up to +3.3V via 10kΩ")

    def test_fields_and_counts(self):
        cnt = {}
        for p in self.data["pins"]:
            self.assertIn(p["grp"], GROUPS, p)
            self.assertIn(p["dir"], DIRS, p)
            self.assertTrue(p["sig"] and p["ds"], p)
            self.assertEqual(p["conn"], "J1" if p["n"] <= 100 else "J2")
            self.assertEqual(p["row"], "odd" if p["n"] % 2 else "even")
            cnt[p["grp"]] = cnt.get(p["grp"], 0) + 1
        self.assertEqual(cnt, {"GND": 51, "PWR5": 6, "PWR33": 3, "PWR18": 2, "GPIO": 28, "ETH": 13, "SD": 12,
                               "USB": 3, "PCIE": 8, "CSI0": 6, "CSI1": 10, "HDMI0": 12, "HDMI1": 12,
                               "DSI0": 6, "DSI1": 10, "I2C0": 2, "CTRL": 10, "RSV": 3, "VDAC": 1, "ANALOG": 2})

    def test_directions(self):
        p = self.pins
        self.assertEqual(p[1]["dir"], "gnd")
        self.assertEqual(p[77]["dir"], "power_in")
        self.assertEqual(p[84]["dir"], "power_out")
        self.assertEqual(p[78]["dir"], "power_in")
        self.assertEqual(p[15]["dir"], "out")
        self.assertEqual(p[3]["dir"], "bidir")
        self.assertEqual(p[99]["dir"], "in")
        self.assertEqual(p[100]["dir"], "out")
        self.assertEqual(p[110]["dir"], "out")
        self.assertEqual(p[116]["dir"], "in")
        self.assertEqual(p[76]["dir"], "nc")
        self.assertEqual(p[128]["dir"], "in")
        self.assertEqual(p[157]["dir"], "out")

    def test_pairs(self):
        paired = [p for p in self.data["pins"] if "pair" in p]
        self.assertEqual(len(paired), 64)
        for p in paired:

#!/usr/bin/env python3
"""Слой «Даташит»: PDF → data/cm4_datasheet.json.

Источники: RP-008168-DS-4-cm4-datasheet.pdf (табл. 6 — пины, табл. 7/8 — дифф-пары),
RP-008248-DS-1-bcm2711-peripherals.pdf (табл. 94 — ALT-функции GPIO0–27).
Запуск из корня репо: python3 tools/extract_datasheet.py   (нужен pdftotext, poppler-utils)
"""
import json
import re
import subprocess
from pathlib import Path

ROOT = Path(__file__).resolve().parent.parent
CM4_PDF = ROOT / "RP-008168-DS-4-cm4-datasheet.pdf"
BCM_PDF = ROOT / "RP-008248-DS-1-bcm2711-peripherals.pdf"
OUT = ROOT / "data" / "cm4_datasheet.json"

SKIP = re.compile(r"^\s*(Pinout\s+\d+|Raspberry Pi Compute Module 4|Pin\s+Signal\s+Description)\s*$")
ROW = re.compile(r"^\s{1,4}(\d{1,3})\s{2,}(\S.*?)\s{2,}(\S.*)$")
GROUP_PREFIX = [("Ethernet_", "ETH"), ("SD_", "SD"), ("USB_", "USB"), ("PCIe_", "PCIE"),
                ("CAM0_", "CSI0"), ("CAM1_", "CSI1"), ("HDMI0_", "HDMI0"), ("HDMI1_", "HDMI1"),
                ("DSI0_", "DSI0"), ("DSI1_", "DSI1"), ("AnalogIP", "ANALOG")]
DIR_BY_SIG = {
    "EEPROM_nWP": "in", "Pi_nLED_Activity": "out", "SD_VDD_OVERRIDE": "in", "SD_PWR_ON": "out",
    "GPIO_VREF": "power_in", "SCL0": "bidir", "SDA0": "bidir", "WL_nDisable": "bidir",
    "BT_nDisable": "bidir", "RUN_PG": "bidir", "nRPIBOOT": "in", "PI_LED_nPWR": "out",
    "Camera_GPIO": "out", "GLOBAL_EN": "in", "nEXTRST": "out", "USB_OTG_ID": "in",
    "PCIe_CLK_nREQ": "in", "PCIe_nRST": "out", "VDAC_COMP": "out", "Reserved": "nc",
    "Ethernet_SYNC_IN": "in", "Ethernet_SYNC_OUT": "out",
}


def pdftext(path):
    return subprocess.run(["pdftotext", "-layout", str(path), "-"], check=True,
                          capture_output=True, text=True).stdout.splitlines()


def parse_pins(lines):
    start = next(i for i, l in enumerate(lines) if l.startswith("Pinout for the Raspberry Pi Compute Module 4"))
    end = next(i for i, l in enumerate(lines) if l.startswith("All ground pins should be connected"))
    pins, cur = [], None
    for l in lines[start + 1:end]:
        if not l.strip() or SKIP.match(l):
            continue
        m = ROW.match(l)
        if m and (cur is None or int(m.group(1)) == cur["n"] + 1):
            cur = {"n": int(m.group(1)), "sig": m.group(2).strip(), "ds": m.group(3).strip()}
            pins.append(cur)
        elif cur is not None:
            cur["ds"] += " " + l.strip()
    for p in pins:
        p["ds"] = re.sub(r"\s+", " ", p["ds"]).replace("( ", "(").replace(" .", ".")
    return pins, end


def parse_pair_lengths(lines):
    """Табл. 7 (100 Ω) и 8 (90 Ω): имя сигнала -> {z, skew}. lines — текст ПОСЛЕ таблицы пинов."""
    out, z = {}, None
    for l in lines:
        if "100Ω differential pair signal lengths" in l:
            z = 100
        elif "90Ω differential pair signal lengths" in l:
            z = 90
        elif l.startswith("5. Power"):
            break
        elif z:
            m = re.match(r"^\s+([A-Za-z0-9_]+_[PN])\s+([\d.]+)\s*$", l)
            if m:
                out[m.group(1)] = {"z": z, "skew": float(m.group(2))}
    return out


def parse_alt(lines):
    """Табл. 94 BCM2711: GPIO0..27 -> {pull, alt[6]}."""
    i = next(i for i, l in enumerate(lines) if "Table 94. GPIO Pins" in l)
    j = next(i for i, l in enumerate(lines) if "Table 95. GPIO Pins" in l)
    rows, alt, k = lines[i:j], {}, 0
    while k < len(rows):
        m = re.match(r"^\s+GPIO(\d+)\s+(High|Low|-)\s+(.*)$", rows[k])
        if m and int(m.group(1)) <= 27:
            cells = re.split(r"\s{2,}", m.group(3).strip())
            nxt = rows[k + 1] if k + 1 < len(rows) else ""
            if nxt.strip() and not re.match(r"^\s+GPIO\d+", nxt):
                # строка-продолжение ("SRW_N", "MOSI", "SCLK") клеится к ячейке по позиции колонки
                pos = len(nxt) - len(nxt.lstrip())
                best = None
                for c in cells:
                    if rows[k].find(c) <= pos + 1:
                        best = c
                cells[cells.index(best)] = best + " " + nxt.strip()
                k += 1
            while len(cells) < 6:
                cells.append("")
            alt[str(int(m.group(1)))] = {"pull": m.group(2), "alt": cells[:6]}
        k += 1
    return alt


def classify(sig):
    if sig == "GND":
        return "GND"
    if sig.startswith("+5V"):
        return "PWR5"
    if sig.startswith("CM4_3.3V") or sig == "GPIO_VREF":
        return "PWR33"
    if sig.startswith("CM4_1.8V"):
        return "PWR18"
    if re.fullmatch(r"GPIO\d+", sig) or sig in ("ID_SD", "ID_SC"):
        return "GPIO"
    if sig in ("SCL0", "SDA0"):
        return "I2C0"
    if sig == "Reserved":
        return "RSV"
    if sig == "VDAC_COMP":
        return "VDAC"
    for pre, grp in GROUP_PREFIX:
        if sig.startswith(pre):
            return grp
    return "CTRL"


def direction(sig, grp, ds):
    if sig in DIR_BY_SIG:
        return DIR_BY_SIG[sig]
    if grp == "GND":
        return "gnd"
    if grp == "PWR5":
        return "power_in"
    if grp in ("PWR33", "PWR18"):
        return "power_out"
    if grp in ("GPIO", "SD", "USB", "I2C0"):
        return "bidir"
    if grp == "ETH":
        return "out" if "_nLED" in sig else "bidir"
    if grp == "ANALOG":
        return "in"
    if sig.startswith("PCIe_CLK_"):
        return "out"
    for word, d in (("Input", "in"), ("Output", "out"), ("Bidirectional", "bidir")):
        if ds.startswith(word):
            return d
    raise ValueError(f"нет правила направления для {sig}: {ds[:50]}")


def gpio_num(sig, ds):
    m = re.fullmatch(r"GPIO(\d+)", sig)
    if m:
        return int(m.group(1))
    m = re.search(r"BCM2711 GPIO ?(\d+)", ds)
    return int(m.group(1)) if m else None


def attach_pairs(pins, lengths):
    by_sig = {p["sig"]: p for p in pins}
    for p in pins:
        m = re.fullmatch(r"(.+)_([PN])", p["sig"])
        if not m:
            continue
        partner = by_sig.get(f"{m.group(1)}_{'N' if m.group(2) == 'P' else 'P'}")
        if partner is None:
            continue
        info = lengths[p["sig"].replace("USB_", "USB2_")]  # табл. 8 зовёт пару USB2_P/N
        p["pair"] = {"partner": partner["n"], "z": info["z"], "skew": info["skew"]}


def main():
    cm4 = pdftext(CM4_PDF)
    pins, end = parse_pins(cm4)
    for p in pins:
        p["conn"] = "J1" if p["n"] <= 100 else "J2"
        p["row"] = "odd" if p["n"] % 2 else "even"
        p["grp"] = classify(p["sig"])
        p["dir"] = direction(p["sig"], p["grp"], p["ds"])
        g = gpio_num(p["sig"], p["ds"])
        if g is not None:
            p["gpio"] = g
    attach_pairs(pins, parse_pair_lengths(cm4[end:]))
    data = {"source": {"cm4": CM4_PDF.name, "bcm2711": BCM_PDF.name},
            "pins": pins, "alt": parse_alt(pdftext(BCM_PDF))}
    OUT.write_text(json.dumps(data, ensure_ascii=False, indent=1) + "\n", encoding="utf-8")
    print(f"pins={len(pins)} pairs={sum('pair' in p for p in pins)} alt={len(data['alt'])} -> {OUT}")


if __name__ == "__main__":
    main()
```

#!/usr/bin/env python3
"""Вшивает data/cm4_datasheet.json и data/project.json в cm4_pinout.html между /*DATA-START*/ и /*DATA-END*/.
Запуск из корня репо: python3 tools/build.py
"""
import json
import re
from pathlib import Path

ROOT = Path(__file__).resolve().parent.parent
HTML = ROOT / "cm4_pinout.html"
MARK = re.compile(r"/\*DATA-START\*/.*?/\*DATA-END\*/", re.S)


def dumps(obj):
    # "</" не должно встретиться внутри <script>; на всякий случай экранируем
    return json.dumps(obj, ensure_ascii=False, separators=(",", ":")).replace("</", "<\\/")


def build():
    ds = json.loads((ROOT / "data" / "cm4_datasheet.json").read_text(encoding="utf-8"))
    prj = json.loads((ROOT / "data" / "project.json").read_text(encoding="utf-8"))
    block = "/*DATA-START*/\nvar DATA = " + dumps(ds) + ";\nvar PROJECT = " + dumps(prj) + ";\n/*DATA-END*/"
    src = HTML.read_text(encoding="utf-8")
    if len(MARK.findall(src)) != 1:
        raise SystemExit("в cm4_pinout.html должен быть ровно один блок DATA-START…DATA-END")
    new = MARK.sub(lambda m: block, src, count=1)
    HTML.write_text(new, encoding="utf-8")
    return len(new)


if __name__ == "__main__":
    print(f"ok {build()} bytes -> {HTML}")
